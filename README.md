# 🎨 Калькулятор натяжных потолков — демо

> Демонстрационная версия онлайн-калькулятора стоимости натяжных потолков
> для компаний-установщиков. Полностью статический сайт на чистом HTML, CSS
> и JavaScript. Работает на GitHub Pages без бэкенда, базы данных и сборки.

## 📋 Что это

Готовый шаблон сайта для локальной компании по установке натяжных потолков:

- **Клиент** вводит размеры помещения, выбирает материал и профиль,
  отмечает светильники, люстры, углы и обходы труб — и сразу видит
  предварительную стоимость с разбивкой по статьям.
- **Заявка** формируется как ссылка на Telegram или VK с готовым текстом
  сообщения (имя, телефон, расчёт). Клиент отправляет её одним кликом.
- **Админка** позволяет менять тексты, тарифы, контакты, SEO и мессенджер
  без пересборки сайта. В демо-версии изменения сохраняются в `localStorage`
  текущего браузера.

Это **демонстрационная** версия продукта. Она нужна, чтобы:

1. Быстро показать заказчику, как будет работать калькулятор.
2. Дай возможность владельцу покрутить тарифы и посмотреть пересчёт.
3. Проверить вёрстку и UX до подключения бэкенда.

Продакшен-версия с PHP 8 + SQLite, реальными заявками в БД и защищённой
админкой — отдельный проект (ссылка в разделе «Связь с продакшеном»).

## ✨ Возможности

### Калькулятор
- Площадь и периметр по длине/ширине помещения
- Материал полотна (матовое / глянцевое / сатиновое — редактируется)
- Тип профиля (ПВХ / алюминиевый — редактируется)
- Углы (по умолчанию 4 входят в базовую цену)
- Точечные светильники, люстры, обходы труб
- Наценка за высоту выше порога
- Минимальная стоимость заказа
- Мгновенный пересчёт при любом изменении поля
- Понятная детализация: откуда взялась каждая цифра

### Заявка
- Имя, телефон, согласие на обработку персональных данных
- Автоматически собирает все параметры расчёта в текст сообщения
- Формирует ссылку `https://t.me/USERNAME?text=...` или `https://vk.me/SHORTLINK?text=...`
- Безопасное кодирование текста через `encodeURIComponent`
- Проверка обязательных полей перед отправкой
- Индикатор загрузки и защита от повторного нажатия

### Админка (`/admin.html`)
- **Без пароля** — это публичное демо, и в шапке явно об этом сказано
- Разделы: «Компания и тексты», «Тарифы», «Мессенджер», «SEO», «Фото»
- Добавление/удаление материалов и профилей
- Предпросмотр итогового сообщения в реальном времени
- Сохранение в `localStorage` (переживает F5, доступно только в этом браузере)
- Кнопка «Сброс» возвращает всё к значениям из `config.json`
- Загрузка фото с ограничением по размеру (до 1,5 МБ каждое, ~4 МБ суммарно)

### Общее
- 📱 Mobile-first адаптивная вёрстка, без горизонтальной прокрутки
- 🌐 Русский интерфейс
- 🚫 Ноль зависимостей: нет jQuery, Bootstrap, Tailwind, сборщиков
- 🔍 `title` и `meta description` подтягиваются из настроек
- ♿ Понятные подписи полей, крупные тач-таргеты
- 🛡 Никакого исполнения пользовательских строк через `innerHTML` — только `textContent`

### Шаблон сообщения

Поддерживаются переменные:

| Переменная | Что подставляется |
|---|---|
| `{name}` | Имя клиента |
| `{phone}` | Телефон клиента |
| `{price}` | Итоговая сумма, например `17 300` |
| `{details}` | Многострочная разбивка расчёта |

Пример:

```
Здравствуйте! Меня зовут {name}, телефон {phone}.
Хочу заказать замер. Предварительный расчёт: {price} ₽.

{details}

Прошу связаться для подтверждения.
```

## ⚠️ Ограничения демо-версии

Это важно понимать до показа заказчику:

| Что | Как ведёт себя здесь |
|---|---|
| **Хранение настроек** | Только `localStorage` текущего браузера. У другого посетителя — свои настройки |
| **Заявки** | Не сохраняются на сервере. Пишутся в `localStorage` как имитация для админки |
| **Автоматическая отправка** | Нет. Открывается чат мессенджера с готовым текстом — клиент отправляет сам |
| **Авторизация админки** | Нет пароля: любой может зайти и что-то поменять (у себя в браузере) |
| **Фото работ** | Хранятся в `localStorage` как base64, лимит ~4 МБ на всё |
| **Реальные персональные данные** | Не собирай их через это демо: они не шифруются и живут только в браузере клиента |
| **SEO** | `title`/`description` устанавливаются JS — для поисковиков это базовая оптимизация, а не полноценная индексация |

## 🔗 Связь с продакшеном

Продакшен-версия — тот же фронтенд + бэкенд на PHP 8 + SQLite:

- заявки сохраняются в `data/database.sqlite`;
- админка защищена паролем и PHP-сессией;
- тарифы и тексты живут в БД и применяются для всех посетителей;
- сервер **сам пересчитывает** стоимость перед сохранением заявки — доверять
  сумме из браузера нельзя;
- загрузка фото в `/img/` с проверкой MIME и генерацией случайного имени.

Единственное отличие в конфиге — `"mode": "prod"` и `"apiUrl": "api.php"`.
**Файлы `index.html`, `admin.html`, `assets/css/style.css`, `assets/js/app.js`,
`assets/js/admin.js` в обеих версиях идентичны** — можно проверить `sha256sum`:

```bash
sha256sum index.html admin.html assets/css/style.css assets/js/app.js assets/js/admin.js
```

Хеши совпадут с продакшен-версией побайтово.

## ❓ FAQ

**Почему нельзя открыть `index.html` двойным кликом?**
`config.json` грузится через `fetch()`, а браузеры запрещают `fetch` по `file://`.
Нужен любой локальный HTTP-сервер (`python3 -m http.server`, `npx serve`, `php -S`).

**Почему мои правки из админки не видны на другом устройстве?**
Так работает демо: изменения ложатся в `localStorage` текущего браузера.
Это фича, а не баг. В продакшене всё хранится в БД.

**Можно ли использовать это как реальный сайт компании?**
Только для показа. Для реального приёма заявок подключай продакшен-версию:
там сервер пересчитывает цену, заявки сохраняются, админка защищена.

**Почему нет React / Vue / сборки?**
Задача — быть максимально простым для развёртывания на любом хостинге и в
любом окружении. Чистый HTML/CSS/JS снимает целый класс проблем: нет node_modules,
нет версий Node, нет CI. Открыл `index.html` — работает.

**Как добавить новую валюту/язык?**
Формат цен — `toLocaleString('ru-RU')` в `app.js`. Язык интерфейса — русский,
зашит в HTML. Форк и правка под свою локаль — 10 минут работы.
